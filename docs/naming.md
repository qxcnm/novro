# 命名说明

## 产品名：Novro

国内传播时读作“诺沃”，英文写法保持为 `Novro`。

选择这个名字的原因：

- 五个字母，短而完整，适合产品界面、API 地址和代码仓库。
- 两个音节，中文口头传播成本低。
- 名称取自 `Nova` 与 `Route` 的组合联想，表达一条面向新一代模型的统一接入通路。
- 不把品牌锁定在某一个模型，后续可以继续接入其他国内或海外模型。
- 相比 `ModelPivot`、`ModelHub` 这类描述性名称，更简短，也更适合作为独立品牌传播。

## 统一命名

- 产品：`Novro`
- 产品全称：`Novro Gateway`
- 中文称呼：`诺沃网关`
- 仓库：`novro`
- Go 模块：`github.com/<organization>/novro`
- 前端：`novro-web`
- 后端：`novro-server`
- 管理后台：`Novro Console`

## 传播语句

主标语：

> 一个接口，接入国内主流大模型。

面向开发者的描述：

> 用一套 API Key，调用 Kimi、GLM、DeepSeek。
