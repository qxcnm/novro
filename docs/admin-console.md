# 管理后台

## 当前实现

`/setup` 负责首次管理员初始化，`/register` 提供可配置的普通用户注册，`/login`
支持本地密码与可选的第三方 OIDC，`/console` 是普通用户登录后的账号页。
`/admin/users` 提供用户列表、搜索、状态筛选、分页、详情、资料与角色编辑、创建、
启用/停用和密码重置。登录后的控制台使用桌面左侧导航，移动端使用同一导航的左侧
抽屉。页面基于原始 shadcn/ui 原语，支持深色、浅色及系统主题。

首次初始化不提供默认密码。部署管理员必须先在服务端环境设置高熵
`NOVRO_SETUP_TOKEN`，浏览器提交相同令牌后才能创建第一个管理员。数据库使用
唯一安装标记与事务保证该操作只能成功一次；完成后应从部署环境删除令牌。

OIDC 用户首次登录时可按 `NOVRO_OIDC_AUTO_REGISTER` 自动创建普通成员。系统不会
按邮箱合并账号，管理员可停用 OIDC 用户，也可以为其设置一个本地恢复密码。

登录后的普通用户菜单只保留“账户”和“API 文档”。账户页集中展示余额与 API Key，
完整 Key 只在创建弹窗中出现一次；管理员额外看到用户、Key 审计、提供商和模型路由
入口。提供商页面只显示凭据提示，模型页面只显示单价和映射，不显示密文。

## 交互约定

- 创建用户、重置密码等短表单使用居中弹窗。
- 停用或启用等需要明确后果的操作使用确认弹窗。
- 用户详情和资料编辑使用右侧抽屉，保留列表上下文。
- 桌面控制台保持固定左侧菜单；窄屏通过菜单按钮打开左侧导航抽屉。
- 菜单和页头位于持久布局中；页面切换只替换右侧内容区，不重新加载整套控制台。
- 操作按钮使用 Lucide 图标和可访问名称，表单错误显示在当前弹窗或抽屉内。

## 1. 页面结构

管理后台包含五块核心页面：

1. 用户
2. API Key 审计
3. 提供商
4. 模型路由
5. 用户余额与流水（在用户详情抽屉中调整）

不在第一版加入复杂的统计大屏、供应商编排、订单中心或销售管理页面。
所有入口都对应已经完成的服务端接口；支付订单、套餐、组织、项目和复杂供应商编排仍不
在页面中出现。

## 2. 用户页面

用户列表展示：

- 用户名
- 显示名称
- 角色
- 状态
- 最近登录时间
- 创建时间

用户操作：

- 创建用户
- 搜索用户和按状态筛选
- 重置密码
- 启用或停用用户
- 查看用户详情
- 修改显示名称和角色

用户列表的余额图标打开右侧抽屉，管理员可以查看最近流水并填写金额和备注。金额使用
人民币，正数增加、负数扣减；服务端用整数微元校验余额不能变成负数。

## 3. API Key 页面

管理员可以查看所有用户的 Key 元信息，但不能查看完整明文 Key。页面展示：

- Key 名称
- 所属用户
- 前缀
- 状态
- 创建时间
- 最近使用时间

管理员可以停用 Key，不能恢复已经撤销的 Key。需要恢复时重新创建。

## 4. 余额调整

余额调整必须填写金额和备注，并自动写入余额流水。页面中明确区分：

- 增加余额
- 扣减余额
- 退款或冲正

调整操作需要记录执行管理员和操作时间。

## 5. 提供商和模型路由

`/admin/providers` 使用创建弹窗和详情抽屉维护 HTTPS 基础地址、协议和加密 API Key；
`/admin/models` 使用创建弹窗和详情抽屉维护对外模型名、上游名称以及输入/输出价格。
停用确认使用确认弹窗。当前没有“测试连接”按钮，避免在没有出口策略时引入任意 URL
探测；真实调用只会从 `/v1` 请求触发，并且网关会阻止内网目标。

## 6. 用户端页面

用户端只保留：

- 登录
- 账户，显示身份、余额和 API Key，并支持创建、复制一次性完整 Key 和撤销
- API 文档；公开入口为 `/docs`，登录后的持久控制台入口为 `/console/docs`
