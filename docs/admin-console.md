# 管理后台

## 当前实现

`/setup` 负责首次管理员初始化，`/register` 提供可配置的普通用户注册，`/login`
支持本地密码与可选的第三方 OIDC，`/console` 是普通用户登录后的账号页。
`/admin/users` 提供用户列表、创建、启用/停用和密码重置。页面使用原始
shadcn/ui 原语，支持深色、浅色及系统主题。

首次初始化不提供默认密码。部署管理员必须先在服务端环境设置高熵
`NOVRO_SETUP_TOKEN`，浏览器提交相同令牌后才能创建第一个管理员。数据库使用
唯一安装标记与事务保证该操作只能成功一次；完成后应从部署环境删除令牌。

OIDC 用户首次登录时可按 `NOVRO_OIDC_AUTO_REGISTER` 自动创建普通成员。系统不会
按邮箱合并账号，管理员可停用 OIDC 用户，也可以为其设置一个本地恢复密码。

API Key、余额流水和用户总览仍按后续路线图实现，本阶段不显示不可用入口。

## 1. 页面结构

管理后台保持三块核心页面：

1. 用户
2. API Keys
3. 余额流水

不在第一版加入复杂的统计大屏、供应商编排、订单中心或销售管理页面。

## 2. 用户页面

用户列表展示：

- 用户名
- 显示名称
- 角色
- 状态
- 当前余额
- API Key 数量
- 最近登录时间
- 创建时间

用户操作：

- 创建用户
- 重置密码
- 启用或停用用户
- 查看用户详情
- 调整余额

## 3. API Key 页面

管理员可以查看所有用户的 Key 元信息，但不能查看完整明文 Key。页面展示：

- Key 名称
- 所属用户
- 前缀
- 状态
- 创建时间
- 最近使用时间

管理员可以停用 Key，不能恢复已经撤销的 Key。需要恢复时重新创建。

## 4. 余额调整

余额调整必须填写金额和备注，并自动写入余额流水。页面中明确区分：

- 增加余额
- 扣减余额
- 退款或冲正

调整操作需要记录执行管理员和操作时间。

## 5. 用户端页面

用户端只保留：

- 登录
- 总览，显示余额和最近 Key
- API Keys
- API 使用说明
